📊 Credit Card Transaction Analysis Dashboard

This project is a Credit Card Transaction Analysis Dashboard designed to analyze and visualize customer spending behavior in an interactive and insightful way.
The dashboard helps understand monthly spending trends, category-wise expenses, transaction patterns, and customer insights using visual analytics.

🔍 Key Highlights
Total Spend: 73.69M
Total Transactions: 1M
Average Transaction Value: 70.28

These KPIs give a quick overview of overall credit card usage and spending intensity.

📅 Monthly Spend Analysis
Displays month-wise spending trends from January to December
Helps identify:
High spending months (e.g. December)
Low spending periods
Useful for understanding seasonal spending behavior

🛒 Category-wise Spending Breakdown

The dashboard classifies spending into major categories such as:
Shop Online
Personal Care
Home
Entertainment

📌 Insights:
Shop Online contributes the highest share of total spending
Entertainment and Home categories also show consistent usage
A donut chart is used to clearly show the percentage contribution of each category.

💳 Average Transaction Value by Category
This section compares average transaction value across different categories:
Helps understand where users spend more per transaction
Useful for targeted offers and business decision-making

👥 Transaction by Gender
Visual comparison of transactions between Male and Female users
Shows transaction count distribution clearly
Helpful for customer segmentation and marketing strategy
